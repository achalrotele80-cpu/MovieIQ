# 🎬 MovieIQ - Movie Success Prediction Dashboard

## 📌 Project Overview

MovieIQ is an interactive Streamlit dashboard that analyzes movie data and predicts whether a movie is likely to be successful using Machine Learning.

A movie is considered successful when:

Revenue > Budget

The project includes Exploratory Data Analysis (EDA), Statistical Analysis, Random Forest Classification, and an interactive prediction dashboard.

---

## 🎯 Objectives

- Analyze movie datasets
- Identify factors affecting movie success
- Perform statistical testing
- Train a Machine Learning model
- Build an interactive dashboard
